# 🤖 AI Student Assistant

### Your Smart Study & Career Companion

> A student-focused Web Development project that brings study planning, notes summarization, career guidance, and interactive question answering into one simple web application.

---

## 📌 About the Project

**AI Student Assistant** is a frontend-based web application designed to provide students with useful academic and career-related tools in one place.

The project focuses on creating a clean, responsive, and easy-to-use interface while demonstrating practical **HTML, CSS, and JavaScript** skills.

---

## ✨ Key Features

### 🤖 AI Chat
Ask study-related questions and receive helpful predefined responses for common topics such as:
- Exam preparation
- Focus and concentration
- Memory improvement
- Time management
- Resume preparation
- Interview preparation
- Coding and programming

### 📚 Study Plan
Create a simple day-by-day study plan by entering:
- Subjects
- Number of days available

### 📝 Notes Summary
Paste a paragraph or notes and generate a concise summary by identifying important sentences.

### 💼 Career Helper
Explore learning roadmaps for different career paths, including:
- Web Development
- Data Science & AI
- Cybersecurity
- Government Jobs
- Python Development
- Java Development
- App Development
- Cloud Computing
- Software Testing
- UI/UX Design

### 💬 Chat History
Previous questions and responses remain visible during the session.

### 🗑️ Clear History
Clear the current chat history with one click.

### 📱 Responsive Interface
The layout adapts to desktop, tablet, and mobile screen sizes.

## 🚀 How to Run the Project

### Option 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The application will open in your web browser.

### Option 2 — Using VS Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Run the file using a browser or Live Server.
4. Start using the application.
